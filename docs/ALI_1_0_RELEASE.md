# Ali 1.0 Release

Date: 2026-06-27

Ali 1.0 is the first owner-ready distributable baseline for Project Ali.

This release includes the WPF assistant, guarded local coding workflows, installer and uninstaller flows, backup and restore, curated sources and topics, local PDF tooling, Visual Studio Companion integration, Piper and KittenTTS voice support, and the full day-one voice pack packaging path.

Future fixes after this point should be treated as patches, starting at `1.0.1`.
